# v6：連続する整数の共通約数と、円分因子による新しい排除

日付：2026年11月5日

対象は一貫して

\[
\boxed{\binom{\binom ij}{\binom{k}{\ell}}
=\binom{i^2}{j^2}+\binom{k^2}{\ell^2}}
\tag{E}
\]

である。右辺の二乗は、二項係数の上下の添字に付いている。
通常の非負整数と、定義される二項係数の範囲で考える。

**全体の解の分類は未完了であり、具体的な解もまだ得られていない。**
今回の成果は、二つの残存分岐に対する新しい一様排除と必要条件である。
以下の無限範囲の主張は、各証明ノートの議論による。
Python の有限計算と Lean の検証範囲は第5節で区別する。

## 1. ell=1、j=i-3：i-1 から新しい共通約数を得た

\[
n=i,\quad A=\binom n3,\quad
X=\binom{n^2}{(n-3)^2},\quad r=\min(k,A-k)
\]

と置く。元の式は

\[
\binom Ar=X+k^2.
\]

これまでの証明から、残る解には

\[
n\ge104,\qquad 3n<r<\frac{10n}{3}
\tag{1}
\]

が必要である。以下は k=r と k=A-r の両方を含む。

### 1.1 共通約数をそのまま三乗の条件に移せる

D が A と X の共通約数なら、

\[
r\binom Ar=A\binom{A-1}{r-1}
\]

より D は rk² を割る。k は法 D で r または -r に等しいので、

\[
\boxed{D\mid r^3.}
\tag{2}
\]

従って最大公約数 gcd(A,X) 全体も使える。

従来の n/gcd(n,3) に加えて、新しく

\[
\frac{n-1}{\gcd(n-1,6)}
\]

が A と X の両方を割ることを証明した。要点は
t=n-1、N=n²、m=(n-3)² と置いた選び方の恒等式

\[
\binom N2\binom{N-2}{m-2}=\binom m2 X
\]

である。t は C(N,2) を割り、C(m,2) は法 t で6に等しい。
したがって t は6Xを割る。A についても t は6Aを割る。
二つの共通約数は互いに素なので、(2) から

\[
\boxed{
Q=\frac n{\gcd(n,3)}
\frac{n-1}{\gcd(n-1,6)}
\mid A,\quad Q\mid X,\quad Q\mid r^3.
}
\tag{3}
\]

**n と n-1 を同時に制約できるようになったことが、この枝の進展の中心である。**

### 1.2 n-1 が平方自由なら完全に排除できる

平方自由とは、どの素数の二乗でも割り切れないことをいう。
新しい定理は

\[
\boxed{\ell=1,\quad j=i-3,\quad i-1\text{ が平方自由}
\quad\Longrightarrow\quad\text{解なし}.}
\tag{4}
\]

証明の絞り込みを記す。d=gcd(n-1,6)、s=(n-1)/d と置く。
s が平方自由なので s|r。さらに

\[
c_3(z):=\prod_{p\mid z}p^{\lceil v_p(z)/3\rceil}
\]

と定義すると、z|u³ と c₃(z)|u は同値である。
c=c₃(n/gcd(n,3)) は r を割り、s と互いに素である。
そこで r=ts と書けば c|t であり、(1) から

\[
3d+\frac3s<t<\frac{10d}{3}+\frac{10}{3s}.
\]

n≥104 より s>17。従って整数 t の可能性は次だけである。

| d | t |
|---:|---|
| 1 | なし |
| 2 | なし |
| 3 | 10 |
| 6 | 19 または20 |

d=3、t=10 では c₃(n)|10 と n≡1 mod 3 から、
n≥104 の可能性が n=250,1000 だけになる。
1000-1 は9で割れる。n=250 では r=830 となり、
法83で左辺は65、右辺は0なので矛盾する。

d=6、t=19 では n=19^a、1≤a≤3 だが、9|n-1。
d=6、t=20 では n=5^b、1≤b≤3 だが、4|n-1。
いずれも平方自由性に反する。これで全範囲の排除となる。

詳細：[v6_common_divisor.md](v6_common_divisor.md)。

## 2. 合成数：対数幅と、理論上の有限範囲への還元

### 2.1 r は3nの直上の狭い区間にある

二項係数の積表示と階乗の積分評価から、n≥1024 では

\[
\boxed{3n<r<3n+\frac{3n}{4\log n}}
\tag{5}
\]

を証明した。log は自然対数である。証明の定数は有理数の
不等式まで戻して確認しており、浮動小数点の近似に依存しない。

\[
R=\frac{n}{c_3(n/\gcd(n,3))}
\]

と置く。分母は n と r を割るから、正の整数 r-3n も割る。
従って r-3n≥n/R。(5) と合わせると

\[
\boxed{R>\frac43\log n,\qquad n<e^{3R/4}}
\tag{6}
\]

が必要である。

### 2.2 R≤12 の無限族を完全排除

R≤12 なら、(6) より n<e⁹<8192。
小さい n も含め、104≤n≤8191 だけ調べればよい。
c=c₃(n/gcd(n,3)) として n=cR、r=c(3R+t) と書くと、

\[
t\ge1,\qquad 3t<R
\]

だから、各 n に対して t は高々3個である。

この**証明された有限範囲**の全2,180組 (n,r)、両分岐の全4,360式を、
17以下の素数を法とする矛盾で排除した。生成時と検証時で
候補の列挙順・素因数分解法・Lucas 剰余の計算法を変えて照合した。

\[
\boxed{\ell=1,\quad j=i-3,\quad
i/c_3(i/\gcd(i,3))\le12
\quad\Longrightarrow\quad\text{解なし}.}
\tag{7}
\]

例えば、平方自由な奇数 m に対する n=4m,8m,16m はすべて含まれる。
条件 R≤12 が正確な定理であり、この例示より広い。
証明書は v6_offset_composite_certificates.json に全件収録した。

### 2.3 残る第一添字の個数は O(X^(3/4))

U²、V² をそれぞれ n、n-1 の最大の平方約数とする。
(3) の二つの因子から、次の必要条件を得た。

\[
\boxed{n-1<20U^2V^2.}
\tag{8}
\]

実際、g=gcd(n,3)、d=gcd(n-1,6)、
c₁=c₃(n/g)、c₂=c₃((n-1)/d) と置けば、
c₁c₂|r、R=n/c₁、S=(n-1)/c₂ から n-1<(10/3)RS。
また R≤gU²、S≤dV²、gd≤6 なので (8) となる。

D=max(U,V) とすれば D² は n または n-1 を割り、
n≤20D⁴ である。固定した D について、n≤X の個数は

\[
2\min(X/D^2,20D^2)+2
\]

以下。この和を D=(X/20)^(1/4) の前後で分けることで、

\[
\boxed{
T(X):=\#\{n\le X:\text{この枝の解の第一添字になり得る }n\}
=O(X^{3/4}).
}
\tag{9}
\]

つまりこの枝の第一添字の候補は自然密度0である。
四変数全体の解の個数についての定理ではなく、
この疎性だけで残る候補の非存在が示されたわけでもない。

詳細：[v6_offset_composite.md](v6_offset_composite.md)。

## 3. 素数冪：通常の重複因子だけでは足りない

引き続き ell=1、j=i-3 の枝である。
奇素数 q に対する

\[
b^{q-1}\equiv1\pmod{q^2}
\]

という条件を、底 b の Wieferich 条件という。

今回、解が i=2^a または5^a であるための次の必要条件を証明した。

\[
\boxed{
\begin{aligned}
i=2^a&:\ \exists q\mid2^a-1,\quad
2^{q-1}\equiv1\pmod{q^2},\quad q\notin\{1093,3511\};\\
i=5^a&:\ \exists q\mid5^a-1,\quad
5^{q-1}\equiv1\pmod{q^2},\quad q\notin\{20771,40487\}.
\end{aligned}}
\tag{10}
\]

q は奇素数である。これは無条件の必要条件であり、
表示した集合が Wieferich 素数を尽くすという仮定はない。

### 3.1 指数から来る重複と、例外的な重複を分ける

f=ord_q(b)、e_q=v_q(b^f-1) と置くと、二項展開で証明した
付値の持ち上げから

\[
v_q(b^a-1)=e_q+v_q(a),\qquad
e_q=v_q(b^{q-1}-1)
\]

となる。そこで

\[
W_b(a)=\prod_{\substack{q\mid b^a-1\\q\text{ 奇素数}}}q^{e_q-1}
\]

と置き、指数 a に由来する因子を分離する。以前の正確な付値条件と
(3) を合わせると、

\[
\boxed{
W_2(3h)>
\frac{2^{h+1}}{10h}(1-2^{-3h})
}
\tag{11}
\]

および、許される a=3d-1 に対して

\[
\boxed{
W_5(a)>
\frac{3\cdot5^{(a+1)/3}}{20a\epsilon_a}(1-5^{-a}),\qquad
\epsilon_a=\begin{cases}1&a\text{ 奇数},\\3&a\text{ 偶数}\end{cases}
}
\tag{12}
\]

を得る。右辺は指数的に増える。
必要な小指数 2^9、2^12、5^5、5^8 は、新しい r の約数が
既に10n/3を超えるので直接排除した。

### 3.2 指定した二素数だけでも足りない理由

厳密な剰余計算で、次の位数と e_q=2 を確認した。

| 底 | q | ord_q(b) | e_q |
|---:|---:|---:|---:|
| 2 | 1093 | 364 | 2 |
| 2 | 3511 | 1755 | 2 |
| 5 | 20771 | 10385 | 2 |
| 5 | 40487 | 40486 | 2 |

底2で例外的な素因数がこの二つだけなら W₂≤3,837,523。
どちらかが現れるには位数が3hを割る必要があるので h≥364。
しかし (11) の下界は既に h≥32 でその積を超える。

底5でも同様に W₅≤840,955,477 だが、位数から a≥10385。
(12) の下界は許される a≥59 でその積を超える。従って (10) が従う。
指数 a が q で何度も割れる効果は、既に v_q(a) として分離済みである。

一般の固定した奇素数 P≥7 にも定量的な拡張がある。
詳細：[v6_offset_prime_powers_wieferich.md](v6_offset_prime_powers_wieferich.md)。
この証明に abc 予想や素数の分布についての仮説は使わない。

## 4. i=jp^3：別の素数を使い、実数評価と合同条件を結びつけた

別の残存形

\[
i=jp^3,\quad k=p,\quad\ell=1,\quad
p\text{ 素数},\quad j\text{ 奇数},\quad j+2\le p<2j
\]

を扱う。前段階で j≤100 は排除済みなので、残る候補では p≥103。
前回得た G(j,p)>0 から、今回は明示的に

\[
\boxed{\frac p2<j<
p\left(\frac12+\frac1{12\log p+2}\right)<\frac{10p}{19}}
\tag{13}
\]

と評価した。

### 4.1 p²+p+1 の素因数構造を制約

\[
N=\Phi_3(p)=p^2+p+1
\]

と置く。新しい必要条件は

\[
\boxed{q^{v_q(N)}\le j^2\quad\text{すべての素数 }q\text{ について}.}
\tag{14}
\]

この区間では、N が3以外の相異なる素因数を少なくとも二つ持つことと
同値になる。したがって

\[
\boxed{N=q^a\text{ または }3q^a\quad\Longrightarrow\quad\text{解なし}.}
\tag{15}
\]

理由は、q^a>j² と仮定すると
A=C(jp³,j) は法 q^(floor(a/2)+1) で1になる一方、
p はこの法より小さくなり、外側の二項係数が法 q で0になること。
もう一つの二項係数 C(j²p⁶,j²) は法 q で1になる。
元の等式が p²≡-1 mod q を要求するが、
q|p²+p+1 から p³≡1 mod q でもあるため矛盾する。

### 4.2 N=7q も完全排除できた

q が素数で

\[
p^2+p+1=7q
\]

の場合も、全範囲で排除した。この場合 (13) より
q>p、q<j²<2q となる。法 q の Lucas の桁計算が

\[
\binom{\binom{jp^3}{j}}p\equiv0,\qquad
\binom{j^2p^6}{j^2}\equiv1+14j^2(p-1)
\pmod q
\]

を与えるので、

\[
q\mid42j^2+p-1.
\]

t=(42j²+p-1)/q は、大小関係から71≤t≤81、
偶奇から偶数、法3では1である。従って t=76 に固定され、

\[
\boxed{294j^2=76p^2+69p+83}
\tag{16}
\]

を得る。

ここで (16) は j²/p²>38/147 を要求する。
一方 p≥3⁹=19683 なら (13) より

\[
\frac jp<\frac{121}{238},\qquad
\left(\frac{121}{238}\right)^2<\frac{38}{147},
\]

となり矛盾する。これで p<19683 という上限が証明された。

残りも (16) を法16、49で見て、p²+p+1=7q と q≡1 mod 3
から得た p≡2 mod 3 と合わせると

\[
p\equiv107\quad\text{または}\quad1355\pmod{2352}
\]

に限られ、103≤p<19683 では17個だけである。
各候補で (76p²+69p+83)/294 を隣接する平方数の間に挟み、
全17個を排除した。完全な表は証明ノートに掲載している。
候補の生成は任意の探索上限ではなく、(13) と (16) の矛盾から
得た上限による。素数性の判定を使わなくても全17整数が失敗する。

**実数評価の根の位置と、合同式から得た二次方程式の傾きが
一致できないことを使い、この型を全範囲で排除した。**

詳細：[v6_large_prime_cyclotomic.md](v6_large_prime_cyclotomic.md)。

## 6. 残っている具体的な課題

1. ell=1、j=i-3 で、R>12 かつ n-1 が平方自由でない合成数。
   (5)、(8) は新しい必要条件だが、R に一様な上限はまだない。
2. 同じ枝の素数冪で、例外的な Wieferich 因子が十分現れる可能性。
   (10) を証明したことは、それ以外の Wieferich 素数の非存在を
   証明したことではない。
3. i=jp³ の枝で、p²+p+1 が二つ以上の非3素因数を持ち、
   今回の7q型にも当たらない場合。例えば7q^a、a≥2、
   qは3,7以外の素数、という形など。
4. 以前の下側 i=j+4 の残存区間と、その他の未排除分岐。

次に使える具体的な入力は、共通約数 gcd(A,X) のさらなる構造、
連続する n と n-1 の重複因子、円分因子の各素数における Lucas の
上位桁である。必要条件が両立するかを、今回得た明示的な
不等式・合同式とともに調べる段階に進んだ。
